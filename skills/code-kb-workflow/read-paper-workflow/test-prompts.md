# Test Prompts

Use these prompts to sanity-check that the skill triggers for realistic requests.

## Prompt 1

Help me read this paper. I need the main contribution, the section map, and the one argument path that matters most.

## Prompt 2

I am turning this whitepaper into knowledge-base notes. Separate the core claims from the marketing language, trace one evidence chain, and summarize the open questions.

## Prompt 3

How should I read this technical report without getting lost? Start with the structure, then explain the method, the strongest evidence, and the stated limitations.

## Prompt 4

Compare these two papers on agent memory. I care about what each one actually claims, what evidence supports it, and where their limitations differ.
